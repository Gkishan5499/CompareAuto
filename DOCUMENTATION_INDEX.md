## 🎓 Key Concepts

### Component Structure
- **OnRoadPriceCalculator**: Main model/overview calculator
- **VariantPriceCalculator**: Variant-specific compact calculator

### Data Flow
1. User selects fuel type
2. Component calls `/api/pricing/calc`
3. Backend calculates breakdown
4. Component displays results

### Supported Fuel Types
- 🔥 Petrol
- ⛽ Diesel
- 💨 CNG
- 🔋 Hybrid
- ⚡ EV (Electric)

### Price Components
1. Ex-Showroom Price (base)
2. RTO (varies by state & fuel)
3. Insurance (varies by state & fuel)
4. GST (5%, fixed)
5. TCS (1%, fixed)
6. FASTag (₹2,500, fixed)

### Coverage
- States/UTs: 37 (all of India)
- Fuel types: 5
- Unique configurations: 185+
